# evanmikayla.github.io

Interactive cybersecurity resume and portfolio for Evan Pearlman. Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages.

- `index.html`: resume with an interactive terminal
- `projects.html`: projects and labs (placeholders for upcoming write-ups)
- `style.css` and `main.js`: styling and interactivity
- Add `resume.pdf` to this folder and a "Download resume" button appears automatically.
